# Bundled fonts

Both fonts are licensed under the SIL Open Font License 1.1 and are copied here
from npm packages by `scripts/copy-fonts.mjs` at build time.

- **Pretendard** (Korean body text) — https://github.com/orioncactus/pretendard
- **Chakra Petch** (numerals, clock, readouts) — https://github.com/cadsondemak/Chakra-Petch
